# 到广州做试管的费用试管婴儿具体流程有哪些

到广州做试管的费用？

1、医疗费用。

检查费用：主要是排除不适合进行试管婴儿的传染性疾病，花费大约在2000元左右;

促排卵药物费用：括进口的和国产的，价格还会根据药物的种类而不同，费用大家在1-3万元不等;

取卵取精费用：取精的费用不贵，主要是取卵的费用贵一些，加起来一般是3000-1万元左右;

胚胎移植费用：这个是试管婴儿关键的一步，大约在1万元左右;

胚胎冷冻费用：冷冻胚胎的费用一般也是1万元左右，保管期限是1年;

胚胎筛查费用：筛查的费用大约在万元-2万元之间，目前只有第三代试管才可以进行胚胎筛查;

2、活费用。

酒店住宿：附近酒店住宿一天大概在150-200元左右;

交通出行：杭州邵逸夫医院地址在市中心，交通比较发达，乘坐公交或者是地铁都可以到达，费用比较便宜，自己有车的话还会更方便;

日常饮食：医院附近有很多餐馆，人均消费大约在20元左右;

试管婴儿具体流程

夫妻在准备试管前三个月，做好备孕工作，饮食营养均衡，作息规律不熬夜，适当进行身体锻炼。

还有，做好身体方面的检查。发现问题及时采取有效措施解决，降低赴泰试管婴儿失败的风险。

1、女方月经第.一天见医院的医，做简单的身体检查(注意：当前赴泰试管的话，还需要隔离，不过可以边隔离边做试管。)

2、进入试管周期，开始促排卵、用药(8-10天左右)

3、进行取卵，男方同一天取精

4、实验室体外受精，ICSI技术帮助精卵结合

5、通过5-6天囊胚培育，然后进行PGD、PGS基因检测

6、胚胎移植阶段：挑选健康优质的囊胚，根据试管家庭的育需求进行移植

7、验孕：通过抽血，验HCG值看是否怀孕(或者也可回国验孕)，一个完整周期在25天左右

注意：当前，由于大部分家庭采用冻胚移植，故而整个IVF流程会分为两个部分来完成。

前期阶段10—12天，吃药、促排，然后取卵完成就可以回国。

后期阶段7—10天，胚胎做好再去做冻胚移植，而期间医院会进行胚胎培育，每一步的结果都会实时给到试管家庭，让其了解大致情况，减少担忧和焦虑。
